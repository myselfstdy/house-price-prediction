# 🏠 House Price Prediction

A Machine Learning project that predicts house prices using different regression models.

## 📌 Project Overview

This project analyzes a house price dataset, preprocesses the data, trains multiple Machine Learning models, and compares their performance to predict house prices.

## 🚀 Workflow

The project follows these steps:

1. Load the dataset
2. Explore the data
3. Check missing values
4. Analyze dataset information and statistics
5. Preprocess the data
6. Handle missing values
7. Encode categorical features
8. Split the dataset into training and testing sets
9. Train Machine Learning models
10. Evaluate model performance
11. Compare the models
12. Save the trained model

## 🤖 Models Used

The following Machine Learning models are used:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
